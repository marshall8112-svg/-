# 🚪 퇴사 디데이 계산기 (quit-dday)

- 아이디어: 질문 10개로 퇴사 지수·예상 퇴사일·버티기 칭호를 알려주는 직장인 공감 테스트
- 소개: 질문 10개로 보는 내 퇴사 각 · 대표색 #1F8A70 · 영문 Quit Day Meter
- 콘솔 이름 규칙상 하이픈 불가 → "D-day" 대신 "디데이"

## 흐름
1. 홈 — 시작하기
2. 질문 10개 (보기 4개, 0~3점, 이전 질문으로 돌아가기 가능)
3. 계산 완료 → "결과 보기"
4. 결과 — 퇴사 지수(%) 원형 게이지, 칭호 5단계, 예상 퇴사일 D-n(답안이 같으면 같은 날짜), 월요병·번아웃·탈출 욕구, 생존 팁, 공유/다시 하기

## 광고
- 전면형: "결과 보기" 누를 때
- 보상형: "광고 보고 상사 대처 비법 보기" (보상: 상사 대처 비법 1)
- 배너: 결과 화면 콘텐츠 아래

# 🦶 발가락 연애 테스트 (foot-love-test)

- 원 아이디어: 발 사진으로 성적 취향을 파악하는 코믹 앱 → 전체 이용가 심사를 고려해 **연애 스타일 테스트**로 순화
- 소개: 발 모양으로 보는 연애 스타일 · 대표색 #FF7A59

## 흐름
1. 홈 — 발 사진 올리기 (사진은 기기 안에서 미리보기로만 쓰고 전송하지 않음)
2. 발가락 모양 선택 — 이집트형 / 그리스형 / 로마형 / 모르겠음(사진 시드로 결정)
3. 가짜 분석 연출 → "결과 보기"
4. 결과 — 유형·별명(사진마다 다름)·설명·연애 능력치 4종·찰떡궁합, 공유/다시 하기

## 광고
- 전면형: "결과 보기" 누를 때
- 보상형: "광고 보고 숨겨진 연애 비밀 보기" (보상: 숨겨진 연애 비밀 1)
- 배너: 결과 화면 콘텐츠 아래

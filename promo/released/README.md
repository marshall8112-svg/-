# 출시된 앱 표시

토스에 출시(OPEN)된 미니앱마다 `<앱 id>` 파일이 하나씩 생긴다 (내용: 감지한 날짜). 같은 앱의 출시 알림을 두 번 보내지 않기 위한 기록이다.
PC 의 Claude 예약 작업("미니앱 출시 감시")이 콘솔 MCP 로 출시를 확인하면 이 파일을 만들어 푸시하고,
그 앱의 릴스 다운로드 링크·캡션을 **카카오톡 나에게 보내기**로 보낸다 → 폰에서 직접 인스타에 올린다.

인스타 자동 게시(`.github/workflows/reels-release.yml`)는 저장소 변수 `RELEASE_POST=true` 일 때만 이 파일 푸시로 돈다.
